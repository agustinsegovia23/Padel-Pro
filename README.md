# 🎾 Padel Pro: Camino a la gloria

Sitio web oficial y plataforma promocional para el videojuego indie **Padel Pro**, desarrollado como trabajo final integrador para las materias de Diseño web y Usabilidad, y Frameworks de Desarrollo Web - Año 2026.

## 🚀 Sobre el Proyecto

_Padel Pro_ es una simulación deportiva y aventura narrativa centrada en la superación personal, rivalidades intensas y la redención en el circuito profesional de pádel. El sitio web permite a los usuarios conocer la historia del protagonista, explorar las mecánicas de juego, ver avances multimedia y acceder al área de comunidad y de usuario.

## 🛠️ Tecnologías Utilizadas

- **Backend:** PHP / CodeIgniter 3 (Arquitectura MVC).
- **Frontend:** HTML5, CSS3, Bootstrap 5.
- **Estilos y UI:** Paleta de colores personalizada.
- **Control de versiones:** Git y GitHub.

## 📁 Estructura del Sitio

- **Home:** Presentación principal con diseño de grilla simétrica y llamadas a la acción (CTA).
- **Historia:** Sinopsis y narrativa del videojuego.
- **Gameplay:** Explicación de mecánicas y física de juego.
- **Personajes:** Fichas y perfiles de los personajes.
